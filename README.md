# Virentora — сайт

Одностраничник. Всё в одном файле `index.html` — стили, скрипты, логотип (SVG), иконки. Никаких зависимостей и сборки. Шрифт Inter подтягивается с Google Fonts.

## Что заменить перед публикацией

Открой `index.html` и найди через Ctrl+F:

| Найти | Что это | На что заменить |
|---|---|---|
| `t.me/virentora` | Ссылка на Telegram (3 места) | Свой ник |
| `hello@virentora.com` | Почта (2 места) | Свою почту |
| `https://github.com/` | Ссылка в футере | Свой профиль |
| `#contact` в блоке кейсов | Кнопки «Открыть демо» | Ссылки на живых ботов, когда соберёшь |

Тексты, цены и вопросы FAQ лежат в самом низу файла, в объекте `I` — там два блока, `ru` и `en`. Правишь строку в обоих — меняется на сайте.

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub с именем `virentora` (или любым другим).
2. Залей в него `index.html` и `README.md` — можно просто перетащить файлы в браузере через кнопку **Add file → Upload files**.
3. В репозитории: **Settings → Pages**.
4. В блоке *Build and deployment*: Source — **Deploy from a branch**, Branch — **main**, папка — **/ (root)**. Нажми **Save**.
5. Через 1–2 минуты сайт будет по адресу `https://ТВОЙ_ЛОГИН.github.io/virentora/`.

Если хочешь адрес без папки — назови репозиторий `ТВОЙ_ЛОГИН.github.io`, тогда сайт откроется просто по `https://ТВОЙ_ЛОГИН.github.io/`.

## Свой домен

Когда возьмёшь домен (~1000 ₽/год) — в **Settings → Pages → Custom domain** впиши его, а у регистратора поставь CNAME на `ТВОЙ_ЛОГИН.github.io`. GitHub сам выпустит HTTPS-сертификат, галочку *Enforce HTTPS* включи после того, как домен подтвердится.

## Что внутри

- Липкая шапка с блюром, мобильное меню
- Переключатель RU/EN — весь текст в одном словаре
- Скролл-анимации с каскадом, анимированные счётчики
- Всплывающие карточки: подсветка под курсором, 3D-наклон, магнитные кнопки
- Бегущая строка со стеком (останавливается при наведении)
- Аккордеон FAQ, мягкий световой ореол за курсором
- Уважает `prefers-reduced-motion` — анимации отключаются для тех, кому они мешают
