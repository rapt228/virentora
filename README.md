# Virentora

Статический сайт [virentora.com](https://virentora.com): услуги, демонстрационные работы, процесс, ориентиры стоимости и контакты. Интерфейс на русском и английском. Земля рисуется в браузере с помощью локальной Three.js; сервер приложения и сборщик для публикации не нужны.

## Структура

| Файл или папка | Назначение |
|---|---|
| `index.html` | Семантическая разметка и исходное содержимое страницы |
| `styles.css` | Общая система оформления, адаптивная компоновка и состояния элементов |
| `app.js` | Переводы RU/EN, меню, FAQ и управление интерфейсом |
| `scene-loader.js` | Загрузка модуля сцены и резервный режим при ошибке |
| `earth.js` | Трёхмерная сцена Земли и управление её отрисовкой |
| `cosmic-background.js` | Процедурная туманность; звёзды рисуются отдельно в `earth.js` |
| `assets/` | Локальная Three.js, текстуры Земли, звёздный фон и другие ресурсы |
| `assets/ATTRIBUTION.md` | Источники и условия использования графики и библиотеки |
| `shots/` | Изображения демонстрационных проектов |
| `CNAME` | Существующий домен `virentora.com` для GitHub Pages |

Не открывайте страницу через `file://`: загрузке модулей и текстур нужен HTTP. Содержимое сайта не требует установки npm-пакетов.

## Локальный просмотр

В терминале VS Code откройте папку репозитория и запустите Python 3:

```powershell
Set-Location C:\projects\virentora
python -m http.server 4186 --bind 127.0.0.1
```

Откройте [локальный сайт](http://127.0.0.1:4186). Оставьте терминал работающим на время просмотра. `Ctrl+C` останавливает сервер. Если команда `python` недоступна, установите Python 3 или используйте имеющийся Python launcher: `py -m http.server 4186 --bind 127.0.0.1`.

Проверяйте внешний вид и прокрутку на широком экране и телефоне, обе языковые версии, меню с клавиатуры, FAQ, якоря, паузу движения и поведение без WebGL. Запуск локального сервера не публикует сайт в интернете.

## Git и публикация

Репозиторий: [rapt228/virentora](https://github.com/rapt228/virentora). Основная ветка при подготовке этой версии — `main`. Файл `CNAME` сохраняет существующий домен; для обновления дизайна менять домен или DNS не нужно.

Это разные действия:

1. **Сохранение файлов** меняет локальную рабочую папку. Результат можно посмотреть через локальный сервер.
2. **Commit** фиксирует выбранные изменения в локальной истории Git. Сам по себе обычный локальный commit не обновляет GitHub и сайт.
3. **Push** отправляет коммиты в удалённый репозиторий. В VS Code команда **Sync Changes / Синхронизировать изменения** может включать получение и отправку коммитов; перед ней проверьте ветку и состав изменений.
4. **Публикация GitHub Pages** выполняется отдельно по настройкам репозитория. Если Pages настроен на ветку `main` и корневую папку, push в эту ветку запускает обновление сайта. Фактические настройки нужно проверить в **Settings → Pages**, результат — в **Actions / pages-build-deployment**.

Перед своим commit посмотрите `git status` и diff. В отправляемые изменения должны попасть не только HTML, но и используемые CSS, JavaScript, текстуры и остальные ресурсы. Не отправляйте секреты, локальные базы и временные файлы. После успешной публикации отдельно откройте [virentora.com](https://virentora.com) и проверьте загруженную версию, при необходимости обновив кеш браузера.

Наличие новой версии в этой папке не подтверждает, что она уже опубликована. Для текущего локального редизайна commit, push и изменение настроек публикации не являются частью автоматической подготовки файлов.

## Качество сцены и мобильная плавность

На обычном старте постер Земли не загружается. Сначала показывается процедурный звёздный фон, затем готовая 3D-сфера проявляется за 300 мс. Постер хранится в инертном template и подключается только при ошибке загрузки модуля или WebGL. Во время загрузки сайта нет смены растянутой фотографии на сферу другого размера.

На телефоне и других устройствах с coarse pointer используется отдельный профиль: поверхность и облака 2K, ночь и детали 1K, около 0,92 МБ карт. Облака объединены с поверхностью в один проход; атмосфера отдельная. Сетка 96×64, около 24 тысяч треугольников. На больших экранах сохранена поверхность до 8K, отдельный слой облаков и плотная геометрия.

Мобильная сцена рисуется с целью до 60 кадров/с; нативная прокрутка не ограничивается. DPR ограничен 1,5 и автоматически уменьшается при устойчиво долгих кадрах. Геометрия страницы измеряется при изменении размеров, а не каждый кадр. Небо пересчитывается только при изменении его размеров или восстановлении контекста. В мобильной шапке убрано затратное backdrop blur.

Пауза, prefers-reduced-motion, скрытие вкладки и уход первого экрана из видимой области прекращают непрерывную отрисовку. Реальная частота кадров зависит от устройства. При проверке desktop через мобильный viewport сначала задайте размер, затем перезагрузите страницу: профиль выбирается при старте.

CSS, JS и fallback-постеры имеют версию URL для обновления кеша при публикации. Вместе с index.html отправляйте новые модули и WebP-ресурсы.

## Форма обращения

Форма отправляет POST на `https://formsubmit.co/pavlovlev39@gmail.com`. Собственного сервера для неё не требуется. Поля: необязательное имя, обязательные email и описание задачи. Валидация встроена в браузер; включена стандартная проверка FormSubmit и скрытое поле от спама. На странице объяснено, что данные проходят через этот сервис. Форма работает без JavaScript и не показывает вымышленное сообщение об успешной доставке: ответ обрабатывает сервис.

Перед использованием подтвердите адрес получателя: первая отправка вызывает письмо активации FormSubmit. Нажмите ссылку в своей почте, затем повторите тест с опубликованного `https://virentora.com` и убедитесь, что письмо пришло. До этой проверки доставка не считается подтверждённой. Адрес `hello@virentora.com` не используется: владелец подтвердил основную почту Gmail.

Инструкция сервиса: https://formsubmit.co/ и https://formsubmit.co/documentation. Если меняется почта, обновите `action` формы и снова проверьте подтверждение получателя. Не помещайте пароли от почты, SMTP или токены в HTML/JavaScript.

## Портфолио и появление блоков

Работы разделены мягкими рамками и отдельными поверхностями. Virentora Bot и Knowledge RAG Bot имеют собственные заметные заголовки и оттенки; номера работ, подписи и текст примеров увеличены. Анимация Земли не менялась.

`reveal.js` использует IntersectionObserver: появление один раз, смещение 14 px за 500 мс, задержка внутри ряда до 90 мс. У эффекта нет постоянного обработчика прокрутки, размытия или скрытого начального состояния. Без JavaScript и без поддержки observer всё остаётся видимым. Переход к якорю, клавиатурный фокус и `prefers-reduced-motion` отменяют появление. Блоки, уже видимые после резкого перехода, не затемняются повторно.
